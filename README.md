Что было сделано:
В ходе работы полностью сверстали проект по макету Figma, разбив его на ключевые секции: шапку, обложку, блок с карточками, раздел «Об аукционе» и подвал. Для точного позиционирования колонок мы применили CSS Grid, а для выравнивания элементов внутри блоков — Flexbox. Реализовали фоновые изображения с затемняющим оверлеем, настроили точную типографику, а также решили вопросы с центрированием логотипов и иконок соцсетей. Подготовили код к прохождению строгих автотестов Яндекс.Практикума и исправили синтаксические ошибки форматирования.
